# 情绪钩子 Emotion Hook

## 原则定义
高抽象概念用个人/情绪场景锚定。将抽象、难以记忆的概念与个人经历、情感体验或具体场景关联，利用情绪记忆的优势增强记忆效果。

## 核心理念
- 抽象概念个人化
- 添加情感记忆点
- 使用具体场景描述
- 利用情绪记忆优势

## Agent 规则

### 触发条件
```python
if abstract_noun:
    add_personal_gist()
```

### 实施步骤
1. 识别抽象概念
2. 寻找个人相关经历
3. 添加情感或场景描述
4. 建立概念与经历的关联

## 使用示例

### Bad 反面案例
```
Q: divan 是什么？
A: 软床无扶手
```
**问题**: 纯定义，缺乏个人连接，难以记忆

### Good 正面案例
```
Q: divan 是什么？
A: 像罗伯特爸妈家那张靠墙软床
```
**优点**: 与个人经历关联，有具体场景

### 更多示例
```
# 抽象词汇个人化
Q: serendipity（意外发现）
A: 就像我在旧书店偶然发现那本改变我人生的书

# 技术概念场景化
Q: 死锁(Deadlock)
A: 就像我和室友同时需要对方手里的钥匙才能开门

# 抽象理论具体化
Q: 墨菲定律
A: 记得那次重要面试，偏偏那天下雨又堵车
```

## 实施要点

### 选择合适的锚点
- 个人真实经历
- 强烈的情感体验
- 生动的场景记忆
- 有趣的故事或事件

### 建立关联
- 找到概念与经历的相似点
- 使用类比和比喻
- 强调情感共鸣
- 保持关联的自然性

### 注意事项
- 不要过度复杂化
- 确保关联有助于理解
- 避免误导性的类比
- 保持个人隐私

## 与其他原则的关系

### 协同原则
- **原子事实**: 情绪钩子应该简洁明了
- **最小语境**: 个人场景应该足够简短
- **图像优先**: 可以结合视觉记忆

### 注意事项
- 不要让个人故事喧宾夺主
- 确保核心概念仍然清晰
- 避免过度依赖情绪记忆

## 认知科学依据
- 情绪增强记忆：情感体验的事件更容易记住
- 自我参照效应：与自己相关的信息记忆更深刻
- 情景记忆：具体场景比抽象定义更易回忆
- 编码特异性：记忆与编码时的情境相关

## 适用场景
- 学习抽象词汇
- 理解复杂概念
- 记忆难以可视化的内容
- 掌握哲学或理论知识

## 实施建议

### 创建情绪钩子的步骤
1. 识别抽象或难记的概念
2. 回忆相关的个人经历
3. 找到经历与概念的连接点
4. 用简洁的语言描述场景
5. 测试是否有助于记忆

### 质量检查
- 关联是否自然？
- 是否有助于理解？
- 是否容易回忆？
- 是否保持了概念的准确性？
