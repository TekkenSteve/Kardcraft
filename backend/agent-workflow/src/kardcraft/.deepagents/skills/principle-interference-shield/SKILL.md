# 干扰对冲 Interference Shield

## 原则定义
相似卡片成组出现，并显式标差异。当多个概念具有高度相似性时，应该将它们成对或成组地组织在一起，并明确标注它们之间的差异点，以防止记忆干扰。

## 核心理念
- 易混概念成对出现
- 明确标注差异点
- 同时复习相似概念
- 通过对比强化记忆

## Agent 规则

### 触发条件
```python
if cluster.similarity > 0.8:
    create_pair()
```

### 实施步骤
1. 识别相似度高的概念（相似度 > 0.8）
2. 将相似概念成对或成组组织
3. 在卡片中显式标注差异点
4. 确保同时复习相似概念

## 使用示例

### Bad 反面案例
```
卡片1:
Q: historic 是什么意思？
A: 历史上的

卡片2:
Q: historical 是什么意思？
A: 历史的
```
**问题**: 分开问，无对比，容易混淆

### Good 正面案例
```
并排卡：
Q: historic 强调？
A: 强调历史上重要的、有历史意义的

Q: historical 强调？
A: 强调与历史相关的、历史学的
```
**优点**: 成对出现，差异明确

### 更多示例
```
# 相似词对比
Q: affect vs effect 的区别？
A: affect 是动词（影响），effect 是名词（效果）

# 相似概念对比
Q: 栈(Stack) vs 队列(Queue) 的主要区别？
A: 栈是后进先出(LIFO)，队列是先进先出(FIFO)
```

## 实施要点

### 识别相似概念
- 拼写相似的词汇
- 含义接近的概念
- 容易混淆的术语
- 对立或互补的概念

### 组织方式
- 并排卡片：同时展示两个概念
- 对比卡片：直接问差异
- 系列卡片：多个相似概念的系统对比

### 标注差异
- 使用明确的对比语言
- 突出关键差异点
- 提供记忆锚点
- 添加使用场景区别

## 与其他原则的关系

### 协同原则
- **原子事实**: 每个差异点应该是原子化的
- **无歧义**: 差异描述必须清晰明确
- **情绪钩子**: 可以用个人经历区分相似概念

### 注意事项
- 不要过度对比不相关的概念
- 确保对比有实际价值
- 避免制造不必要的复杂性

## 认知科学依据
- 干扰理论：相似记忆会相互干扰
- 对比学习：通过对比强化差异记忆
- 辨别性编码：明确差异有助于长期记忆

## 适用场景
- 学习外语中的近义词
- 理解相似的技术概念
- 区分容易混淆的术语
- 掌握对立或互补的概念
