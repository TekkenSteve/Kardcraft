# 来源指纹 Source Hash

## 原则定义
任何非公理事实附带"出处+置信标签"。为所有非自明的事实性信息标注来源和可信度，确保知识的可追溯性和可验证性，培养批判性思维。

## 核心理念
- 标注信息来源
- 添加置信度标签
- 区分事实与观点
- 培养批判性思维

## Agent 规则

### 触发条件
```python
if not axiom:
    append_source()
```

### 实施步骤
1. 识别非公理事实
2. 查找可靠来源
3. 添加来源标注
4. 评估并标注置信度

## 使用示例

### Bad 反面案例
```
Q: 咖啡对健康有益吗？
A: 研究表明咖啡可以降低某些疾病风险
```
**问题**: "研究表明"过于模糊，无法验证

### Good 正面案例
```
Q: 咖啡对健康有益吗？
A: 2021 Nature 元分析（高置信）：每天3-4杯咖啡与降低心血管疾病风险相关
```
**优点**: 明确来源、时间、置信度

### 更多示例
```
# 科学研究
Q: 睡眠不足的影响？
A: 2023 Sleep Medicine Reviews（高置信）：长期睡眠不足增加阿尔茨海默病风险

# 技术文档
Q: React 18 的并发特性？
A: React 官方文档 v18.0（权威）：Concurrent Rendering 允许中断渲染

# 统计数据
Q: 2023年全球电动车销量？
A: IEA 2024年报告（高置信）：约1400万辆，同比增长35%

# 历史事实
Q: 第一台计算机何时诞生？
A: ENIAC 1946年（公认史实）：宾夕法尼亚大学，重30吨

# 专家观点
Q: AI对就业的影响？
A: 李开复《AI未来》2018（专家观点，中置信）：50%工作将被自动化
```

## 实施要点

### 来源类型
- 学术论文：期刊名+年份
- 官方文档：组织名+版本
- 书籍：作者+书名+年份
- 新闻报道：媒体+日期
- 专家观点：专家名+出处

### 置信度标签
- **权威**: 官方文档、教科书定义
- **高置信**: 同行评审论文、元分析
- **中置信**: 单一研究、专家观点
- **低置信**: 新闻报道、未验证信息
- **争议**: 存在不同观点

### 标注格式
```
[来源] [年份] [置信度]：[内容]

示例：
Nature 2023（高置信）：...
WHO 官方指南（权威）：...
张三《XX》2020（专家观点）：...
```

## 与其他原则的关系

### 协同原则
- **时间戳TTL**: 来源通常包含时间信息
- **原子事实**: 每个事实独立标注来源
- **无歧义**: 来源标注必须清晰明确

### 注意事项
- 不要给公理或定义添加来源
- 避免过度依赖单一来源
- 定期检查来源的时效性

## 认知科学依据
- 来源监控：记住信息来源有助于评估可信度
- 批判性思维：培养质疑和验证的习惯
- 元认知：了解知识的局限性
- 知识组织：来源是知识网络的重要节点

## 适用场景
- 学习科学知识
- 记忆统计数据
- 掌握技术规范
- 了解历史事实
- 评估专家观点

## 实施建议

### 创建来源指纹的步骤
1. 识别需要来源的信息
2. 查找可靠来源
3. 评估来源可信度
4. 添加来源标注
5. 定期更新验证

### 质量检查
- 来源是否可靠？
- 置信度是否合理？
- 是否需要多个来源？
- 是否需要更新？

### 不需要来源的情况
- 数学定理：勾股定理
- 逻辑公理：A=A
- 定义：圆的定义
- 自明真理：1+1=2
- 个人经历：我的生日

### 需要来源的情况
- 科学发现
- 统计数据
- 历史事件细节
- 技术规范
- 专家观点
- 争议性话题

## 实战技巧

### 快速标注方法
```
# 简化格式
Nature'23(H): ...  # H=高置信
WHO(A): ...        # A=权威
李四'20(M): ...    # M=中置信

# 完整格式
2023 Nature 元分析（高置信）：...
WHO 官方指南 2024（权威）：...
李四《XX》2020（专家观点，中置信）：...
```

### 来源管理
- 建立常用来源列表
- 标注来源可信度等级
- 定期更新来源信息
- 记录来源访问方式

### 批判性思维培养
- 质疑无来源的信息
- 对比不同来源
- 注意利益冲突
- 区分事实与观点
