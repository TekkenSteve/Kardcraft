# 枚举拆片 Enum Slice

## 原则定义
有序列表必做重叠式填空，禁止整段背诵。将长列表切分成重叠的小片段，每片包含3-5个元素，通过重叠部分建立连接，避免整体记忆的认知负担。

## 核心理念
- 列表项重叠式切片
- 避免整体记忆
- 每片包含3-5个元素
- 通过重叠建立连接

## Agent 规则

### 触发条件
```python
if is_ordered_list:
    overlap_cloze(step=1)
```

### 实施步骤
1. 识别有序列表
2. 确定切片大小（3-5个元素）
3. 创建重叠式卡片
4. 确保每个元素至少出现两次

## 使用示例

### Bad 反面案例
```
Q: 26个英文字母是？
A: ABCDEFGHIJKLMNOPQRSTUVWXYZ
```
**问题**: 一口气背诵，认知负担过重

### Good 正面案例
```
卡片1:
Q: 英文字母前三个是？
A: A-B-C

卡片2:
Q: B之后的三个字母是？
A: B-C-D

卡片3:
Q: C之后的三个字母是？
A: C-D-E

...以此类推
```
**优点**: 重叠式切片，每次只记3个，通过重叠建立连接

### 更多示例
```
# 历史朝代
卡片1: 夏-商-周
卡片2: 商-周-秦
卡片3: 周-秦-汉

# 化学元素周期表（前10个）
卡片1: H-He-Li
卡片2: He-Li-Be
卡片3: Li-Be-B
卡片4: Be-B-C

# 编程语言发展史
卡片1: Fortran(1957)-LISP(1958)-COBOL(1959)
卡片2: LISP(1958)-COBOL(1959)-BASIC(1964)
卡片3: COBOL(1959)-BASIC(1964)-C(1972)

# 软件开发流程
卡片1: 需求分析 → 设计 → 编码
卡片2: 设计 → 编码 → 测试
卡片3: 编码 → 测试 → 部署
```

## 实施要点

### 确定切片大小
- 默认3-5个元素
- 根据元素复杂度调整
- 保持切片大小一致
- 确保认知负担可控

### 重叠策略
- 标准重叠：每次移动1个元素
- 大重叠：每次移动1-2个元素
- 小重叠：每次移动2-3个元素
- 根据列表长度选择策略

### 卡片组织
- 使用填空题(Cloze)格式
- 标注序号或位置
- 保持格式一致
- 添加上下文提示

## 与其他原则的关系

### 协同原则
- **原子事实**: 每个切片是一个原子单元
- **最小语境**: 切片大小控制语境复杂度
- **渐进展开**: 可以先学小切片，再扩大

### 注意事项
- 不要切片过小（少于3个元素）
- 不要切片过大（超过7个元素）
- 确保重叠部分有意义

## 认知科学依据
- 工作记忆容量限制（7±2法则）
- 组块化记忆策略
- 序列位置效应
- 重复学习效应

## 适用场景
- 学习字母表、数字序列
- 记忆历史朝代、年代
- 掌握化学元素周期表
- 学习编程语言发展史
- 记忆流程步骤

## 实施建议

### 创建枚举拆片的步骤
1. 识别完整的有序列表
2. 确定合适的切片大小（通常3-5个）
3. 创建重叠式卡片
4. 添加位置或序号提示
5. 测试记忆效果

### 质量检查
- 切片大小是否合适？
- 重叠是否充分？
- 是否覆盖所有元素？
- 是否有助于记忆？

### 特殊情况处理

#### 短列表（少于5个元素）
- 可以不切片，直接记忆
- 或者创建2-3个元素的切片

#### 长列表（超过20个元素）
- 先分大组，再切片
- 使用层级结构
- 添加记忆锚点

#### 无序列表
- 不适用此原则
- 考虑使用其他组织方式
- 或者人为创建顺序

## 实战技巧

### 提示词设计
```
# 位置提示
Q: 第3-5个元素是？
A: C-D-E

# 前后文提示
Q: B之后的三个是？
A: C-D-E

# 填空提示
Q: A-B-[?]-[?]-[?]
A: C-D-E
```

### 复习策略
- 先复习单个切片
- 再复习相邻切片
- 最后尝试完整序列
- 定期检查整体记忆
